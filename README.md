React + Vite + Tailwind + Framer Motion portfolio.

```bash
npm install

npm run build    # production build
```

## Deploy to GitHub Pages
1. Push this project to a GitHub repo (branch `main`).
2. Repo **Settings → Pages → Source: GitHub Actions**.
3. (Optional) Add secrets `VITE_EMAILJS_SERVICE_ID`, `VITE_EMAILJS_TEMPLATE_ID`, `VITE_EMAILJS_PUBLIC_KEY` under **Settings → Secrets and variables → Actions** so the contact form works.
4. Every push to `main` rebuilds and publishes the site.
